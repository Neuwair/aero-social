AeroSocial

My first programming project

This project is a technical showcase designed to highlight my understanding of web fundamentals. Built entirely with vanilla HTML, CSS, and JavaScript, with it, I want to demonstrate core front-end skills, API integration, and simple backend logic.

The design of this website is reminiscent of the early 2000s, it draws from a nostalgic and humanistic Frutiger Aero style, I wanted the UI to look tuneful and somewhat modern.

This is not a production-ready social network, I wanted to show what I can do as a solo developer with a clear focus on architecture, logic, and interface dynamics.

The rest of my projects will make use of frameworks, so stay tuned for new releases.

This project has taken me 5 months to complete. I've faced many difficulties and the website has gone through various re-designs, I've also refactored most of my code to keep it modular and as DRY as I can. I feel rather happy about that, because I've learned a lot and if it wasn't for those mistakes this website wouldn't look as good. Good things take time.
